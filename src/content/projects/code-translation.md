## What I built

LoRA fine-tuning of CodeLlama, Llama 2 and NLLB on 1,079 XLCoST code pairs.

## Results

- CodeLlama-7B's CodeBLEU rose from 43.9 to 78.5, and BLEU from 23.4 to 65.1.
- I also showed that the COMET metric fails to penalize code that doesn't compile, while CodeBLEU does.
